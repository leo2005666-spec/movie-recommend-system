# 清新明亮高级感 · UI 改造清单

## 一、涉及文件（仅样式/CSS，不改业务逻辑）

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `frontend/src/index.css` | 重写 | 设计系统变量 + 全部组件样式 |
| `frontend/src/components/BackgroundFX.jsx` | 简化 | 纯 CSS 渐变慢流动 + 噪点 + 遮罩，移除多 orbs |
| `frontend/src/components/Layout.jsx` | 微调 | 移除 theme-bright body class 逻辑 |
| `frontend/index.html` | 可选 | 字体引用（系统字体优先） |

## 二、不改动的部分

- 所有 `pages/*.jsx` 的组件结构、状态、事件逻辑
- `App.jsx` 路由配置
- API 调用、AuthContext、request
- 路由、链接、表单提交等交互行为

## 三、设计系统落地项

- **色板**：背景 ≥3 层，文字 ≥3 层，强调色 1 个
- **字体**：系统无衬线 + 字重层级
- **组件**：Navbar / Button / Input / Select / Card / Tag / Skeleton 统一样式与状态
- **动效**：hover 轻抬升、focus 环、页面淡入，全部克制

## 四、BackgroundFX 要求

- CSS 渐变慢速流动（或极轻量光斑）
- 细噪点纹理叠加
- 遮罩层保证可读性
- `prefers-reduced-motion` 自动静态
- 无 GIF，低帧率，移动端友好

---

## 五、视觉验收清单

打开页面逐项对照，确认「清新明亮的高级感」达标：

### 整体
- [ ] 页面明亮、通透，无脏灰感
- [ ] 留白充足，对齐统一
- [ ] 背景有轻微流动感（25s 循环），不抢眼
- [ ] 细噪点纹理可见但不刺眼

### 顶部导航
- [ ] 白色半透明 + 毛玻璃，当前路由高亮清晰
- [ ] 链接 hover 有背景反馈，无夸张动效

### 搜索/筛选
- [ ] 输入框、下拉、按钮视觉统一
- [ ] 口味标签（taste-chip）hover 有轻微反馈
- [ ] 选中态仅用 accent 色，不花哨

### 电影卡片
- [ ] 海报比例 2:3 统一，圆角一致
- [ ] hover 轻抬升（约 2px）+ 阴影加深
- [ ] 边框细、阴影柔，无厚重感

### 表单/按钮
- [ ] 输入框 focus 有淡蓝色 focus ring
- [ ] 主按钮 hover 轻抬升，active 有按压感
- [ ] outline 按钮边框清晰

### 信息层级
- [ ] 标题 / 副标题 / 元信息一眼可区分
- [ ] 强调色仅用于：按钮、选中态、链接、重点数字

### 动效
- [ ] 页面进入有约 0.4s 淡入
- [ ] 全部动效克制，无闪烁、弹跳
